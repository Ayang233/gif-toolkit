1.8 主要改动

修复
- 无素材时「开始生成」按钮的文字几乎看不见：禁用态改用 MIUIX 主按钮的标准配色（浅蓝底 + 白字），保留主操作按钮的语义。修前是灰底白字，浅色下对比度只有 1.12:1。
- 深色主题下页面底部有一条比页面亮的色带：底部主操作条与玻璃背景垫色取错了色值，统一为页面底色。
- 顶栏在软件光栅化环境（模拟器）下模糊错位：这类渲染器上回退到渐变背景带，真机不受影响。
- 「GIF 编辑」的旋转滑块档位错误：原来的档位会转出 67.5°，非直角会把画面斜切。改为 0/90/180/270。
- 动态取色下底栏与侧栏的选中项不是主色。
- 下拉弹层的玻璃材质在深色下与顶栏不同档；一级页下拉的采样坐标会差一整页宽。
- 作品操作面板的行标题与面板标题不对齐，最后一行会贴住手势导航条。

调整
- 关于页改用 KernelSU / InstallerX Revived 的原生 textureBlur 实现图标与软件名称，删除自制的渐变填充。
- 关于页图标去掉白底底板，改为纯单色剪影并放大主体。
- 抠图颜色色块补无障碍语义（单选角色、选中状态、颜色名），选中时整行不再跳动。

已知限制
- 关于页图标与软件名称需要硬件 GPU 才会显示；模拟器（swiftshader）上该路径不产出像素，真机正常。
