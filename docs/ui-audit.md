## 已修复

| # | 问题 | 原因 | 处理 |
| --- | --- | --- | --- |
| 1 | 生成页同一次任务出现两条进度条 | 内容区与底部操作条各画一条 | 删除内容区那条，只留 `PrimaryActionBar` |
| 2 | 主按钮底部被屏幕圆角/导航区遮挡 | 固定 12dp 留白，没有考虑屏幕圆角 | 按圆弧几何解出所需留白（`safeBottomGap`） |
| 3 | 竖屏视频导出成横屏 | 预览与导出方向处理不一致，且无条件信任旋转元数据 | 统一 `orientForDisplay` / `fitShortSide`，预览与导出同一路径 |
| 4 | 二级页面转场没有圆角裁剪 | `NavDisplay` 未传 `effects`，默认 `cornerClipRadius = 0.dp` | 传 `rememberDeviceCornerRadius()` |
| 5 | 主题切换是硬切 | `MiuixTheme(controller)` 直接换整套色 | `AnimatedMiuixTheme` 逐色插值（53 个颜色角色，320ms） |
| 6 | 一级页切换生硬 | `Crossfade` 纯淡入淡出 | 改 `HorizontalPager`，点击/滑动都有连续位移 |
| 7 | 关于页图标在浅色下"没有底座" | 白底徽章放在 #F7F7F7 页面上没有边界 | 徽章加 1/108 描边（#14000000） |
| 8 | 三键导航下导航栏与页面之间有一条色差接缝 | 系统给导航栏加了对比度底色 | `window.isNavigationBarContrastEnforced = false` |
| 9 | 桌面图标被圆形遮罩切掉两端 | 横向长条在圆内可用宽度为 `2√(r²−h²)`，0.88/0.80 缩放都超限 | 前景缩到 0.72（实测安全上限） |
| 10 | 没有自适应图标/单色层，主题图标无效 | `res/` 下只有一个 108dp vector | 建 `mipmap-anydpi-v26` + 前景/背景/monochrome，补 `roundIcon` |
| 11 | 主按钮像"孤零零一条"、且进度与按钮是两个图形 | 实心底栏 + 按钮上方独立进度条 | 进度画进按钮内部（底轨 + 进度填充），去掉实心底栏，改竖向渐变遮罩 |
| 12 | 去掉底栏后列表文字从按钮底下透出来 | 禁用态用 `primary.copy(alpha=0.30f)`，半透明 | 改成与页面色不透明混合；同时内容区加渐变让文字提前淡出 |

## 记录但未改

| 问题 | 判断 |
| --- | --- |
| 作品页空态只是一段左对齐文字，视觉偏"裸" | 不是 bug。要做成居中插画+引导按钮属于新设计，等确认要不要加 |
| 禁用态主按钮（浅蓝底 + 白字）对比偏低 | Miuix 的默认禁用配色，KernelSU / InstallerX 一致。改它会脱离库的设计语言，保留 |
| 工具页参数区在空素材时就占满一屏 | 参数是可用状态（不影响生成），空态收起反而会让用户以为没有选项。保留 |
| 生成中按钮的进度填充未做视觉验证 | 模拟器里没有可导入的素材，跑不起一次真实任务。逻辑只有十余行，等真机第一次生成时确认 |

## 未覆盖（需真机）

- **玻璃模糊观感**：模拟器是 swiftshader，模糊会糊成污迹，只能看结构对不对。
- **预测性返回手势手感**：拖动跟手、回弹曲线、五档差异。
- **大圆角机型**：本模拟器为直屏，`safeBottomGap` 的圆角分支没被真正触发。
- **横屏**：Activity 声明了 `configChanges=orientation`，本轮未做横屏回归。
- **Monet 跟随真实壁纸**：模拟器壁纸固定，取色结果不代表实际观感。
