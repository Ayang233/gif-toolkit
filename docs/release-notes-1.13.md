1.13 主要改动

升级
- Miuix 基线升到 0.9.5-beta03（源码基线 3526cfe2，与 tag 指向同一个提交）。这版主要是玻璃和模糊的重组与分配优化、顶栏渐变带重写、TabRow 淡出闪烁修复；AGP 跟着抬到 9.5.2，Compose Multiplatform 仍是 1.13.0-rc01。
- 顶栏渐变带的透明度改成跟随折叠进度（上游行为变化），滚动时浓淡比上一版更贴合折叠位置。这是观感变化，不是回归。

调整
- 「字幕内容」输入框按官方示例第一条重写：标题用 GroupHeader，输入框不再带 label。原来的写法里提示文字和光标分属两层文本，行盒不一致，竖杠比中文字形高一截、整体偏上，开始打字时文字还会往上跳一下。现在框里只有一层，光标就是文字将来的位置。
- 去掉「设置 → 主题」页底部的「调试（仅调试包可见）」分组和「开始按钮配色对比」页。配色已经定了，调试包也不需要这个入口。

说明
- 本轮不新增功能，也不改版式。基线的逐项差异、试过但无效的参数、以及官方示例对照，都记在 docs/miuix-baseline-f3829d3d-to-3526cfe2-diff.md 里。
- 玻璃质感仍然只能真机看：模拟器用的软件渲染不产出模糊像素，本机验证的是布局、启动和交互，不是模糊观感。
