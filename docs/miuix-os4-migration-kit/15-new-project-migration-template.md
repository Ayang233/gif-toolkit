## G. 风险登记

| 风险 | 影响 | 概率 | 缓解 |
|---|---|---|---|
| 目标设备 GPU 不支持模糊 | 玻璃降级 | | 用户开关 + `fallback` |
| `textureBlur` 在真机异常 | About 页需改设计 | | 保留不透明回退分支 |
| 上游 API 变更 | 返工 | | 钉 commit；升级前过检查表 |
| 分页容器坐标问题 | 弹层无背景 | | 采样源录在容器外 |
| 大字体下底栏压内容 | 列表末尾被挡 | | 真机 + 大字验证 |
