1.7 主要改动

修复
- 1200dp 横屏（侧栏展开）时侧栏压住一级页面的列表行：内容让位只算了侧栏宽度，漏掉起始边的系统安全区（横屏时挖孔落在左侧 64dp），而侧栏自己是吃这段安全区的。竖屏挖孔在顶部、横向安全区为 0，所以上一轮没露出来。
- 底部主操作条左端贴屏幕边缘、右端留 12dp：`railStartInset(base)` 的 `base` 参数没被使用。
- 横屏下底部主操作条压在挖孔/侧边系统栏上：这一层不在 Scaffold 内容槽位里，拿不到 `innerPadding`，现在自己取横向安全区。
- 宽屏展开侧栏时顶栏标题没有跟着内容让位，标题偏在内容区左侧。

调整
- 关于页按 InstallerX Revived 的排版重做：入口不再带前置小图标，描述写在副标题里。
- 应用图标与软件名称改为跟随背景色段上色（与背景共用同一个配色状态，不另起一套渐变）。
- 「开源许可」与「第三方许可」合并为一个入口：同一页按「本项目 / 第三方组件 / 归属」分组，正文页共用；`Route.OwnLicense` 随之移除，NOTICE 收进 assets。
- 尺寸统一：说明段落 16→28dp、预览与结果卡内边距 12→16dp、字幕输入框去掉多余横向内边距（字段自带 16dp）、许可正文 16→28dp、预览占位图标走 `IconSizes.Media`。

说明
- 这是 1.8 之前遗漏的一次发布，按当时的代码状态补发；版本与安装包即当时的 1.7（9）。
